## Overview
This repository contains an enhanced responsive and interactive student portfolio website built for ICT251 Activity 3. The project demonstrates semantic HTML5 design, external CSS layout and styling, local JavaScript interactions, and continuous deployment through GitHub to Render.

## Features & Interactivity Included
1. **Compulsory Contact Form Validation & Preview (JS):**
   - Validates user input client-side using `event.preventDefault()`.
   - Rejects blank inputs, whitespace-only entries, and malformed email addresses.
   - Displays a secure local preview using `textContent` stating that data was validated without sending to a server.

2. **Theme Switcher (JS):**
   - Toggles dynamically between Light and Dark visual themes using CSS custom properties (`--var`) and dataset attributes.

3. **Gallery Viewer (JS):**
   - Interactive photo slider with "Previous" and "Next" controls.
   - Handles boundary wraps for seamless photo and caption navigation.

4. **Mobile Navigation Menu (JS):**
   - Provides a mobile toggle button on narrower screen sizes to collapse or reveal section navigation links smoothly.

## Testing & Verification
- **Local Testing:** Verified via Live Server in VS Code with zero Console errors.
- **Responsiveness:** Tested at 375px (mobile) and 1280px (desktop) layouts.
- **Accessibility:** Keyboard tab ordering, high-contrast text ratios, and explicit focus outlines enabled.
