My Learning Plan

My steps for improving my web development skills are:

  1. Practice HTML structure and semantic elements regularly.
  2. Learn CSS layouts, responsive design and basic styling techniques.
  3. Build small websites and test them using VS Code and Live Server.
  4. Learn basic JavaScript after becoming comfortable with HTML and CSS.
